# Greenlight logo

A check mark drawn in dots on a pixel grid, the same dot-matrix language as the app's backdrop.
Its tip is a glowing lime dot: the green light. The wordmark is Geist SemiBold, outlined to
vector paths so it doesn't depend on the font. The dot of the "i" is the same lime light.

| File | Use |
|---|---|
| `greenlight-mark.svg`, `greenlight-mark-1024/512/192.png` | App icon, avatars, social images (full detail) |
| `greenlight-mark-small.svg`, `greenlight-icon-180/64/32/16.png` | Favicon and small sizes (no background grid, bigger dots) |
| `greenlight-logo-on-dark.svg/.png` | Mark + wordmark on dark backgrounds (7239 × 1536 PNG) |
| `greenlight-logo-on-light.svg/.png` | Mark + wordmark on light backgrounds (7239 × 1536 PNG) |
| `greenlight-wordmark.svg` | Wordmark alone, on light backgrounds |

Colours, taken from the interface:

| Name | Hex |
|---|---|
| Night | `#030a24` |
| Night blue | `#0b2a8f` |
| Ink | `#0b1437` |
| Sky (check, start) | `#93c5fd` |
| Lime (the green light) | `#d9f24a` |

PNGs have transparent backgrounds. Keep clear space around the mark of at least a quarter of its
width, and don't recolour the lime light.
