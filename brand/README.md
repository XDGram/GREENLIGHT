# Greenlight logo

A check mark drawn in dots on a pixel grid, rising to a glowing green light: the moment an app
gets the green light. The tiles and colours come from the interface (sky blue hero, near-black
buttons and logo tile, the green used for "passed"). The wordmark is Plus Jakarta Sans Bold, the
interface's font, outlined to vector paths; the dot of the "i" is the same green light.

| File | Use |
|---|---|
| `greenlight-mark-sky.svg`, `greenlight-mark-sky-1024/512/192.png` | Main mark: app icon, social images |
| `greenlight-mark-dark.svg`, `-1024/512/192.png` | On light pages where the interface uses its near-black tile |
| `greenlight-mark-white.svg`, `-1024/512/192.png` | On the sky-blue hero and other blue backgrounds |
| `greenlight-icon-sky.svg`, `greenlight-icon-sky-180/64/32/16.png` | Favicon and small sizes (no background grid, bigger dots) |
| `greenlight-icon-dark.svg`, `greenlight-icon-dark-64/32.png` | Small dark icon |
| `greenlight-logo-on-light.svg/.png` | Mark + wordmark on white (6840 × 1536 PNG) |
| `greenlight-logo-on-sky.svg/.png` | Mark + wordmark on the sky blue (white tile, white text) |
| `greenlight-logo-on-dark.svg/.png` | Mark + wordmark on near-black |
| `greenlight-wordmark.svg` | Wordmark alone |

Colours, taken from the interface:

| Name | Hex |
|---|---|
| Sky | `#2f6fd1` (tile `#2459bd` to `#6aa8f2`) |
| Ink | `#141a22` |
| Green light | `#22b36b`, highlight `#7ef0a8` |
| White | `#ffffff` |

PNGs have transparent backgrounds. Keep clear space around the mark of at least a quarter of its
width, and keep the light green.
